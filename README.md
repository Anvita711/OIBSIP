# 📊 Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview

This project is completed as part of the **Oasis Infobyte Data Analytics Internship (Level 1 - Task 1)**.

The objective is to perform Exploratory Data Analysis (EDA) on the Sample Superstore dataset to identify sales trends, profit distribution, regional performance, and product performance. The analysis provides meaningful business insights using Python and data visualization techniques.

---

## 🎯 Objective

- Understand the structure of the dataset
- Perform data inspection and cleaning
- Analyze sales and profit performance
- Identify top-performing regions and states
- Discover relationships between numerical variables
- Generate business insights and recommendations

## 💡 Key Business Insights

- Technology generated the highest sales among all categories.
- The West region recorded the highest sales.
- California was the top-performing state.
- Discounts negatively affected profitability.
- Phones and Chairs were among the highest-selling sub-categories.

---

## ✅ Business Recommendations

- Increase inventory for high-demand products.
- Focus marketing campaigns on high-performing regions.
- Review discount strategies to improve profitability.
- Improve sales strategies in lower-performing regions.
