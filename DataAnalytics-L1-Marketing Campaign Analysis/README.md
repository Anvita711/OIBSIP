# 📊 Marketing Campaign Analysis

## 📌 Project Overview

This project analyzes a bank marketing campaign dataset using Python to understand customer behavior and identify factors influencing term deposit subscriptions. Through Exploratory Data Analysis (EDA), the project uncovers trends and provides business insights that can help improve future marketing strategies.

---

## 🎯 Objectives

- Analyze customer demographics
- Study marketing campaign effectiveness
- Identify factors affecting deposit subscriptions
- Generate meaningful business insights
- Visualize trends using charts and graphs

---

## 🛠 Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Insights

- Most customers belong to the middle-aged group.
- Customers in management and blue-collar jobs make up a large share of the dataset.
- Customers with longer call durations are more likely to subscribe.
- Marketing effectiveness varies by month.
- Customer account balance appears to influence subscription behavior.
